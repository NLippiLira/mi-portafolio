# Mi Portafolio Personal

## 🎯 Objetivo del proyecto
Portafolio web estático para presentar mis proyectos, habilidades y experiencia como Desarrollador Full Stack JavaScript.

## 🛠️ Tecnologías / Stack
- HTML5
- CSS3 + Bootstrap 5
- JavaScript (Vanilla)
- GitHub Pages (hosting)
- Responsive & accessible design
- UI animations con CSS

## 🚀 Cómo instalar y ejecutar localmente
1. Clonar repo: `git clone https://github.com/NLippiLira/mi-portafolio`
2. Instalar dependencias si es necesario (solo estáticos)
3. Abrir `index.html` en navegador
4. (Opcional) desplegar con GitHub Pages desde la rama `main`
